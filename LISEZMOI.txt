Carnet d'entretien - mise à jour v4.1 (champ « Réalisé par »)

AVANT TOUT : SAUVEGARDE
Dans l'appli : Exporter > sauvegarde complète JSON. Gardez ce fichier de côté.

MISE À JOUR SUR GITHUB
1. Dans votre dépôt GitHub (carnet-entretien) : Add file > Upload files.
2. Glissez tous les fichiers de ce dossier (index.html, store.js, sw.js, manifest.webmanifest, les icônes png, etc.) : ils remplacent les anciens. Commit changes.
3. Attendez 1 à 2 minutes. Fermez complètement l'appli sur le téléphone et rouvrez-la, deux fois si l'ancienne version s'affiche encore.
4. N'ajoutez JAMAIS de fichier de données (sauvegardes, donnees-carnet.json) dans le dépôt.
5. Aucune donnée à réimporter. Mettez à jour tous les appareils qui utilisent le carnet.

NOUVEAUTÉS
- Dans une ligne (entretien, réparation, contrôle, assurance, autre) : champ « Réalisé par » entre le kilométrage et les notes, avec une liste de garages et de personnes. Un nom saisi à la main est ajouté à la liste.
- Paramètres (engrenage) > « Réalisé par » : la liste, avec ajout et retrait (17 noms fournis au départ).
- Le nom s'affiche dans le journal sous la ligne, et dans l'export CSV (colonne « Réalisé par »).
- Les notes existantes (par exemple « GAM AUTO ») ne sont pas modifiées.
