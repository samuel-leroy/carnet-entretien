CARNET D'ENTRETIEN - version 4.3.1

NOUVEAUTE : lignes du journal dépliables
- Touchez n'importe où sur une ligne pour la déplier / replier.
- Ravitaillement : carburant, litres · €/L, consommation, réservoir rempli, station.
- Entretien : réalisé par + contenu des notes.
- Icônes : poubelle (2 touches pour confirmer), crayon (modifier), oeil (vue complète avec la facture jointe).

MISE A JOUR (vos données sont conservées)
1. Faites d'abord un export JSON complet (bouton Exporter) par sécurité.
2. Sur GitHub (repo carnet-entretien) : remplacez tous les fichiers par ceux de ce dossier.
3. Ouvrez l'application, puis rechargez-la une deuxième fois pour activer la nouvelle version.
